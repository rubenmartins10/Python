- Em python constrói-se uma classe para definir o comportamento compartilhado e, em seguida, criar objetos que usam esses comportamentos.

- class ClassName:
    - def __init__(self, name, age):
        - self.name = name
        - self.age = age
    - def sample_method(self):               
        - print(self.name.upper())

    - A classe **ClassName** é composto pela **class** palavra-chave para criar a classe
    - **def __init__(self, name, age)**, é o método especial chamado automaticamente quando um objeto é criado. Ele inicializa os atributos dos objetos.

- A diferença entre uma classe e um objeto é que uma classe é o modelo ou o blueprint, e um objeto é o que é criado usando esse modelo.

- Uma classe define quais dados e comportamento o objeto deve ter, e um objeto contém os dados reais e usa esse comportamento.
